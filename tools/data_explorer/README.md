# Prosus 本地数据浏览器

中文界面，保留葡语原文。展示全部 5,000 行商品记录和 100 条评估查询。

支持商品搜索、一级分类筛选、缺失字段和重复 ID 筛选、价格／订单排序、分页、卡片／表格切换，以及商品详情、行为画像和原始 JSON。查询页可以复制文本或按原词筛选目录。搜索采用关键词匹配，不是语义检索，也未运行相关性评估。

## 打开

最简单的方法：在 Finder 中打开本文件夹，双击 `启动网页.command`。

它会启动本地服务，并在默认浏览器中打开 <http://127.0.0.1:8765/>。服务在后台运行，关闭启动用的终端窗口后仍可访问。如果服务已在运行，不会重复启动。电脑重启后，需要重新双击启动。

也可以在终端中运行：

```sh
cd tools/data_explorer
python3 launch.py start --open
```

第一次启动时，如果缺少 `data.js`，启动器会自动从 `data/` 下的原始 CSV 生成数据。平时启动无需重复生成数据。

停止服务：双击 `停止网页.command`，或运行 `python3 launch.py stop`。

检查是否运行：`python3 launch.py status`。启动日志保存在 `.runtime/server.log`。

如需让服务在终端前台运行，可使用 `python3 serve.py`；该模式需要保留终端窗口，按 Control+C 停止。

也可以直接用浏览器打开 `index.html`；数据通过本地 `data.js` 读取。

图片默认不加载。勾选“加载商品图片”后，浏览器从作业提供的 iFood 图片地址读取图片；加载失败时显示明确的替代文字。页面不调用模型 API，没有外部字体、分析脚本或网站部署。

`prepare_data.py` 读取上一级的两个 CSV，生成 `data.js`；不会修改原始数据。行为统计按原始值显示，未推断时间单位、币种或百分比。

## 保密

本作业材料、数据及解决方案属于保密内容。生成的 `data.js` 也含有完整数据，不应公开发布。该文件已加入本目录的 `.gitignore`。如需提交代码，应使用私有仓库，并按作业约定处理数据文件。

## 更新数据

更换上一级的源 CSV 后，重新运行 `prepare_data.py`，再刷新网页。
