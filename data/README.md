# Data

The assignment data is confidential and is not in Git. Place the two supplied files here:

- `5k_items_curated.csv` — the 5,000 iFood listings
- `queries.csv` — the 100 evaluation queries

Every script and tool reads them from this folder. Generated files (runs, judgments, human labels,
reports) go to `output/`, and models and caches to `.demo-cache/`; both are ignored by Git.
